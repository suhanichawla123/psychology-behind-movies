# The Psychology Behind Movies

A school project website by Suhani Chawla (Class XII Gir, Shiv Nadar School).

**Why do movies make us feel certain emotions?**

1. Emotional connection with characters
2. Fear and suspense
3. Music and emotions
4. Psychological influence of storytelling

The site is plain HTML, CSS and JavaScript, with no build step.

## Run locally

```bash
python -m http.server 8000
```

Then open http://localhost:8000

## Deploy

Hosted on Render as a **Static Site**: no build command, publish directory `.`
